# 归林（Guilin）

2D 森林生存恐怖游戏第一版网页原型。

## 运行

在 `guilin` 文件夹启动任意静态文件服务器，然后打开 `index.html`。例如：

```bash
python3 -m http.server 8766 --directory guilin
```

## 操作

- `WASD`：移动
- `Shift`：奔跑
- `E`：使用篝火或开关木门
- `1-9`：选择对应的快捷格；空快捷格不会执行动作
- 鼠标左键：手持武器时朝点击方向攻击；空手或拿着非武器时采集点击方向的资源
- 鼠标右键：朝点击方向建造当前选择的建筑
- `Esc`：打开/关闭局内暂停菜单；背包打开时会先关闭背包
- `F`：开关手电筒
- `I` 或 `Tab`：打开/关闭物品栏
- `M`：开关声音

玩家动作图使用 6 行 × 8 格、每格 16×16 的手绘 PNG。职业顺序为：枪手、护士、伐木工、守望者、棒球女、科学家。每行前两格是待机，后六格是移动；职业技能暂未启用。

建筑素材图 `assets/forest-assets.png` 使用 8 列 × 6 行、每格 16×16。第 4 行依次为：篝火、木墙、关门、开门、木地板、储物箱、工作台、陷阱。木门靠近后按 `E` 切换，并使用关门/开门两帧。

木墙和关闭的木门可以阻挡怪物，但会被怪物攻击。受损建筑头上会显示耐久条，耐久耗尽后建筑消失。陷阱可以对怪物造成伤害，命中三次后损坏。

地图大小为 3000×3000 个地块，每格 48×48 像素，总世界尺寸为 144000×144000 像素。游戏只绘制镜头周围约 345 个地块，避免一次处理全部 900 万格。地面只生成草地、水和沙滩，不生成深色草地、石头地、泥土地或道路；湖泊按区域确定生成，沙滩只会出现在紧挨水面的方块上。木材、石头和浆果会随玩家移动按 16×16 格区域动态载入。

物品栏共有 12 格，开局为空，目前会保存采集到的木材、石头和浆果。物品按照实际获得先后进入最前面的空格，不再固定排列；可以拖到空格中移动，也可以拖到另一个物品上交换位置。数量为 0 时对应格子清空；点击已有的浆果可消耗 1 个并恢复 12 点生命。打开物品栏时游戏暂停。

画面底部有 9 格快捷栏，开局 9 格全部为空，不能选择预先放好的建筑、食物或武器。采集到木材、石头或浆果后，它们会按照获得先后进入最前面的空格并显示实时数量；数量降为 0 时对应格子会自动清空。其他物品可以继续使用剩余空格。

进入游戏前会预加载玩家图、场景图和像素字体。单个素材请求失败时会自动重试三次，全部准备完成后才会启用“进入森林”按钮；仍然失败时可点击“重新加载素材”。

主界面提供“新游戏”“继续游戏”和“设置”。设置面板可以调节总音量、夜晚亮度和雾气浓度，也可以关闭屏幕震动或模仿者突脸效果，并支持切换全屏；这些选项会保存在当前浏览器中。

进入游戏后按 `Esc` 会暂停时间，并打开“继续游戏、保存游戏、设置、退出到主界面”菜单；退出时也会自动保存。选定职业后会立即建立存档，游戏过程中每 20 秒自动保存一次；玩家的位置、生命、资源、背包和快捷栏顺序、建筑、怪物、时间与已采集资源都会恢复。存档保存在当前浏览器中，主界面的“继续游戏”会读取它。

玩家开局为空手。快捷栏中以后放入并选择建筑物品时会进入建造模式，画面显示 48 像素网格；移动鼠标可选择上、下、左、右方向，目标格会显示建筑虚像。绿色格可以建造，红色格表示位置被挡住。

木墙与木门的碰撞盒会跟随图块底部的有效像素，并根据上、下、左、右建造方向一起旋转。储物箱和工作台也会阻挡玩家，木地板与陷阱可以走过。

画面会在白天、黄昏、夜晚和黎明之间平滑变色。夜晚有方向性手电筒、篝火动态光、漂移薄雾和边缘暗角；玩家受伤时会短暂红闪并轻微震动，低生命值会让 HUD 提示变红。

深夜会限制玩家视野：手电筒光锥与篝火安全范围之外会被黑暗遮住。夜雾会变浓，远处偶尔亮起红眼；用手电筒照向红眼时，它们会迅速淡去。

树和浆果丛生成前会检查根部中心及四周地面，只有全部落在草地时才会生成，因此植物不会出现在水面或沙滩上。无效候选位置会被跳过并继续寻找，地图仍会保持原来的资源数量。

深夜的整体遮光更强：手电筒外接近全黑，关闭手电筒后只保留较小的篝火安全范围；手电筒光锥内部也保留冷暗夜色，不会把地面照得像白天一样明亮。

恐怖气氛会贯穿全天：画面降低饱和度并加入冷色压暗、动态颗粒与漂浮尘屑。大型雾团会以不同速度和方向漂移，同时上下浮动、旋转、伸缩并改变浓度。夜晚的外围暗幕更深，手电照射范围更短并会偶尔闪烁，浓雾和远处红眼也会更明显。画面上不会额外覆盖大型前景阴影。

手电筒、篝火及以后新增的光源会分别从夜幕遮罩中移除黑暗，再合并成为同一个亮区；多个光源重叠时不会因为遮罩重复计算而重新变黑。

左键会根据当前快捷栏物品类型自动切换动作。只有标记为武器的物品会触发攻击；空手、建筑材料、食物或空快捷格都会尝试采集玩家面对方向、68 像素范围内的资源。右键仍然只负责建造，`E` 只处理木门和篝火互动。
