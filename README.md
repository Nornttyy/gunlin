# 归林（Guilin）

2D 森林生存恐怖游戏第一版网页原型。

## 运行

在 `guilin` 文件夹启动任意静态文件服务器，然后打开 `index.html`。例如：

```bash
python3 -m http.server 8766 --directory guilin
```

## 操作

- `WASD`：移动
- `Shift`：奔跑
- `E`：采集、互动或开关木门
- `1-6`：在快捷栏选择木墙、木门、木地板、储物箱、工作台或陷阱
- `7`：从快捷栏快速食用浆果
- `B`：消耗材料建造当前选择的建筑
- `Space`：近战攻击
- `F`：开关手电筒
- `I` 或 `Tab`：打开/关闭物品栏

玩家动作图使用 6 行 × 8 格、每格 16×16 的手绘 PNG。职业顺序为：枪手、护士、伐木工、守望者、棒球女、科学家。每行前两格是待机，后六格是移动；职业技能暂未启用。

建筑素材图 `assets/forest-assets.png` 使用 8 列 × 6 行、每格 16×16。第 4 行依次为：篝火、木墙、关门、开门、木地板、储物箱、工作台、陷阱。木门靠近后按 `E` 切换，并使用关门/开门两帧。

木墙和关闭的木门可以阻挡怪物，但会被怪物攻击。受损建筑头上会显示耐久条，耐久耗尽后建筑消失。陷阱可以对怪物造成伤害，命中三次后损坏。

地图地面只生成草地、水和沙滩，不生成深色草地、石头地、泥土地或道路。湖泊按照固定规则生成，沙滩只会出现在紧挨水面的方块上。

物品栏共有 12 格，目前会保存木材、石头和浆果。采集浆果后会先放入物品栏，点击浆果可消耗 1 个并恢复 12 点生命；打开物品栏时游戏暂停。

画面底部有 9 格快捷栏。前 6 格放置建筑，第 7 格放置浆果并与物品栏数量同步，第 8、9 格暂时留空；可以按数字键或用鼠标点击。
